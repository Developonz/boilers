# Общий месячный цикл детекторов и риска

Уточнение запроса: весь автоматический риск и графики должны быть готовы в
разделе 3. Классификаторы продолжаются по месяцам вместе с детекторами;
раздел 7 не запускает новое обучение риска на полной итоговой истории.

1. Перевести независимые эксперименты в возобновляемые месячные шаги.
   Координатор проходит котлы одной группы синхронно по датам, сохраняя
   прежний порядок операций и checkpoints каждого регрессора.
2. После шагов котлов месяца собрать причинные признаки с непрерывным
   подтверждением тревог через границы месяцев. Fit риска видит только
   прошлые строки и метки, известные на начало месяца; прогноз — текущий месяц.
3. Продолжать прежнюю голову риска новыми зрелыми примерами + replay,
   сохранять постоянный резерв калибровки. Пересоздание только по прежним
   явным причинам несовместимости/отзыва истории, без финального полного fit.
4. Кешировать каждую голову/месяц с цепочкой зависимости, записывать
   доступность, оценки и готовность после каждого шага. Присоединять голову
   к текущему и соответствующему месячному экспорту для дашборда.
5. Обновлять те же карточки раздела 3 сразу с риском. Раздел 7 читает
   сохранённый риск и разбирает подтверждённые причины; риск заново не fit.
6. Проверить порядок двух котлов, отсутствие будущих меток, фактический
   рост деревьев, восстановление после прерывания и экспорты; выполнить
   настоящий Run All и собрать переносимый комплект.

Операции выполняются последовательно внутри единого месячного расписания:
параллельные тяжёлые native-fit не добавляются. Старые регрессионные состояния
контракта 4 совместимы; новая цепочка риска строится один раз по сохранённым
причинным признакам. Схема выбранных классификационных меток не меняется.
