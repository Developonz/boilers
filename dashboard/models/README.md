# Экспортированные модели

Сюда помещаются полные папки моделей, сохранённые обучением legacy.
Пример структуры для дашборда:

```text
models/
  K-1/
    aakr/
      final/
        config.json
        model.py
        ...остальные файлы экспорта...
      2025-03/
      2025-04/
```

В data/boilers.json для этого примера:
`model_dir: models/K-1/aakr/final`, `history_dir: models/K-1/aakr`.
Каждая папка месяца содержит свой полный экспорт. Название папки котла
и значение model_unit выбираются по фактическому экспорту; латинская K
и кириллическая К — разные символы в пути.

Для локального использования допустимы пути ../legacy/models_legacy/... .
Относительные пути считаются от dashboard/. Для Docker модели должны
попадать внутрь образа, обычно через эту папку models/.
