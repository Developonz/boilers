# Интерфейс дашборда

`src/` содержит исходники React и страницы авторизации.
`dist/` содержит готовую сборку, которую backend отдаёт браузеру.

Локальная сборка: `npm run build`.
На чистом окружении зависимости устанавливаются через `npm ci` по присланному
package-lock.json; в нём сохранён корпоративный реестр пакетов.
В Docker эта сборка выполняется автоматически. Общие инструкции — в ../README.md.
